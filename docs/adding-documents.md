# Добавление PDF-документа

Документы добавляются вручную, без админки: файл кладётся в репозиторий, запись о нём —
в каталог `src/data/pdfs.ts`. После пересборки у документа появляется страница просмотра
по адресу `/view/<id>`.

## Шаги

### 1. Положить файл

Скопируйте PDF в `public/pdf/` — **имя файла не меняйте**, оригинальное имя остаётся и
именем файла при скачивании:

```bash
cp ~/Downloads/"26-0007 - Ivanov - Cardiology Review_2026.08.01.pdf" public/pdf/
```

### 2. Запустить скрипт списка

```bash
npm run pdfs
```

Скрипт покажет все PDF-файлы и их `id`. Для файла, которого ещё нет в каталоге, выдаст
готовый блок записи со сгенерированным `id` и распознанным индексом:

```
+ 26-0007 - Ivanov - Cardiology Review_2026.08.01.pdf
    нет в каталоге — добавьте в src/data/pdfs.ts запись:
    {
      id: 'k3mqx8vb2p',
      index: '26-0007',
      title: '26-0007 - Ivanov - Cardiology Review_2026.08.01',
      description: '',
      fileName: '26-0007 - Ivanov - Cardiology Review_2026.08.01.pdf',
    },
```

### 3. Добавить запись в каталог

Вставьте блок в массив `entries` в `src/data/pdfs.ts` и вручную уточните `title` и
`description`. Поля:

- `id` — **случайный** opaque-slug (генерирует скрипт `npm run pdfs`). Не привязывайте id
  к номеру работы: по id не должно быть возможно перебором выйти на чужие документы.
- `index` — индекс работы `YY-NNNN`; скрипт подставляет его из начала имени файла.
  Служебное поле (для будущей админки/поиска), на сайте не отображается.
- `title`, `description` — произвольный текст; показываются в info-панели просмотрщика,
  `<title>` страницы и aria-label canvas'а.
- `fileName` — должно точно совпадать с именем файла в `public/pdf/`.

### 4. Пересобрать и опубликовать

```bash
npm run build:gh && npm run deploy-gh
```

(или `npm run build` для локальной проверки, см. [Деплой](deployment.md)).

## Проверка

```bash
npm run preview   # затем открыть http://localhost:4321/view/<id>
```

Проверьте: документ загружается, работает переключение страниц и кнопка «Скачать».

## Частые ошибки

| Симптом                           | Причина                                       |
| --------------------------------- | --------------------------------------------- |
| `/view/<id>` отдаёт 404           | нет записи в `entries` или не пересобран сайт |
| «Не удалось загрузить документ»   | `fileName` не совпадает с именем файла        |
| 404 на сам файл `/pdf/<fileName>` | файл лежит не в `public/pdf/`                 |
