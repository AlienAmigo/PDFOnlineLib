# PDF Viewer

Статический сайт для просмотра PDF-документов в браузере. Стек: **Astro 7** (статическая
генерация), **TypeScript**, **SCSS**, **PDF.js**. Бэкенда нет — сайт собирается в статику
и работает на любом веб-сервере, объектном хранилище или GitHub Pages.

## Возможности

- Просмотр PDF в браузере по прямой ссылке вида `/view/<id>`: постраничная навигация,
  масштабирование, скачивание файла.
- Главная страница (пока — заглушка «В разработке») и страница 404.
- Единый шаблон: шапка с логотипом, футер с копирайтом.
- Добавление документов — вручную: файл + запись в каталоге (без админки и базы данных).

## Быстрый старт

Требуется **Node.js >= 22.23.4** (актуальное требование Astro 7).

```bash
npm install       # установка зависимостей
npm run dev       # dev-сервер: http://localhost:4321/
npm run build     # сборка под корень (/)
npm run build:gh  # сборка под GitHub Pages (/PDFOnlineLib/)
npm run preview   # локальная проверка собранного сайта
npm run preview:gh  # проверка GH-сборки по /PDFOnlineLib/
npm run deploy-gh # сборка под GH Pages и публикация в ветку gh-pages
npm run lint      # ESLint
npm run format    # Prettier: автоформатирование
```

## Структура проекта

```
public/pdf/         PDF-файлы (отдаются как статика)
src/
  config.ts         название сайта, копирайт, все пути
  components/       Header, Footer, Toolbar (разметка + стили рядом с компонентом)
  data/pdfs.ts      каталог документов (id, название, описание, имя файла)
  layouts/          общий шаблон страниц (Header + slot + Footer)
  pages/            страницы: главная, 404, /view/[id]
  scripts/          клиентская логика просмотрщика (PDF.js)
  styles/           глобальные стили + vars/ (дизайн-токены — CSS-переменные)
```
